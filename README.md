# خَيْط

منصة عربية تحول البريد الإلكتروني إلى محادثات أعمال واضحة بين الشركات وعملائها.

## النسخة الحالية

- صندوق محادثات متعدد العملاء
- البحث والتصفية وحالات المحادثة
- قراءة الرسائل والرد عليها بأسلوب تطبيقات المحادثة
- إضافة عميل جديد بالبريد الإلكتروني
- بيانات العميل والوسوم والموظف المسؤول
- تصميم متجاوب للكمبيوتر والجوال

## التشغيل

```bash
pnpm install
pnpm dev
```

## الربط الفعلي القادم

تحتاج بيئة الإنتاج إلى قاعدة بيانات متعددة الشركات، نظام دخول وصلاحيات، وربط مزود بريد يدعم الإرسال والبريد الوارد عبر Webhooks مثل Resend.
